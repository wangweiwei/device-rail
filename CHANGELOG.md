# Changelog

All notable project changes will be documented here. DeviceRail follows
[Semantic Versioning](https://semver.org/) for released packages; wire protocol
compatibility is additionally governed by explicit negotiated protocol
versions.

## [Unreleased]

## [0.3.0] - 2026-07-29

### Added

- Bilingual open-source documentation and project navigation.
- Apache-2.0 licensing and package metadata.
- Contribution, security, conduct, support, and repository-maintenance guides.

- Versioned JSON-RPC device protocol, generated JSON Schema, and cross-language
  Golden Fixtures.
- Rust Driver kernel, conformance suite, Sessions, Evidence Store, cancellation,
  device routing, leases, and graceful shutdown.
- Android, iOS, HarmonyOS, native desktop, Playwright, RDP, plugin, and
  distributed Driver integrations.
- TypeScript and Python clients, provider-neutral Tool Adapter, Execution
  Recorder, offline/live Visualizers, WebSocket event streaming, and media
  evidence streams.
- Deterministic Linux/macOS/Windows release archives with manifests, SBOM,
  provenance, and signature-verification contracts.
